## 📱 نظرة عامة على المشروع

**رادار المصروف (Radar Al-Masrouf)** هو نظام مالي شخصي متكامل مبني بتقنية **Flutter**، مصمم خصيصاً لتوفير تجربة مستخدم (UX) فائقة السلاسة لإدارة الجوانب المالية اليومية:

✅ **إدارة المشتريات** - تتبع ذكي لقوائم التسوق وسجل الأسعار.  
✅ **الميزانيات الشهرية** - ميزانية مرنة لكل فئة مع تنبيهات ذكية.  
✅ **الرصيد الجانبي (Side Balance)** - إدارة أموال بطلات وعملات متعددة بشكل منفصل.  
✅ **مدير الفواتير (Bills Manager)** - تتبع الالتزامات الدورية والفواتير الثابتة.  
✅ **أهداف الادخار (Savings Goals)** - حدد أهدافك وراقب تقدمك نحو تحقيقها.  
✅ **إدارة الديون الذكية** - تكامل كامل بين سجل الديون ورصيد المحفظة.  
✅ **نظام الخزنة (Smart Vault)** - توفير آلي ويدوي مع دعم للعملات المختلفة.  
✅ **النسخ الاحتياطي المحترف** - حماية بياناتك مع خيارات الحفظ والاستعادة اليدوية والتلقائية.

يعمل التطبيق **100% بدون اتصال إنترنت (Offline-First)** مع خصوصية تامة للبيانات.

## ✨ الميزات الرئيسية

### 🏦 **1. المحفظة المركزية وتعدد العملات**
- **إدارة أرصدة متعددة**: (SYP, USD, EUR, SAR, AED) في واجهة واحدة.
- **سجل المعاملات**: تتبع دقيق لكل قرش يدخل أو يخرج من محفظتك.
- **التصريف الفوري**: تحويل الأموال بين العملات داخل التطبيق مع تحديث الأرصدة تلقائياً.

### 🛍️ **2. رادار المشتريات الذكي**
- **إدارة الفئات**: 12 فئة مدمجة مع إمكانية إضافة فئات مخصصة بأيقونات ألوان فريدة.
- **سجل الأسعار**: التطبيق يتذكر آخر سعر لكل منتج لمساعدتك في اتخاذ قرارات الشراء.
- **ميزانية الفئة**: تنبيهات فورية عند إضافة عناصر تتجاوز ميزانية الفئة المحددة.

### 📉 **3. مدير الالتزامات والفواتير (New 🚀)**
- **فواتير دورية**: سجل اشتراكاتك، إيجارك، أو فواتيرك (يومية، أسبوعية، شهرية).
- **الدفع والتحكم**: نظام "دفع الآن" أو "تخطي" مع إمكانية التراجع لسحب المبلغ مجدداً للمحفظة.
- **تكامل المحفظة**: عند دفع أي فاتورة، يتم الخصم تلقائياً من العملة المناسبة في محفظتك.

### 💰 **4. الرصيد الجانبي (Side Balance 🌐)**
- **أموال منفصلة**: نظام مخصص للأموال التي لا تود خلطها بمصروفك اليومي.
- **تعدد العملات**: دعم كامل لجميع العملات العالمية.
- **التحويل للمحفظة**: سهولة نقل المبالغ من الرصيد الجانبي لمصروفك الأساسي عند الحاجة.

### 🎯 **5. أهداف الادخار (Savings Goals)**
- **تحديد الأهداف**: أنشئ أهدافاً مالية (شراء هاتف، سفر، بناء منزل).
- **تتبع التقدم**: شريط تقدم مرئي يوضح النسبة المئوية المتبقية لتحقيق الهدف.
- **سجل الإيداعات**: تتبع متى وكم وضعت في كل هدف.

### 📊 **6. التحليلات المالية المتقدمة**
- **تقارير دورية**: مقارنة الصرف بين الأشهر المتعاقبة.
- **توزيع النفقات**: رسوم بيانية تفاعلية توضح أكثر الفئات استهلاكاً للمال.
- **الرصيد المدور**: حساب تلقائي للمبالغ المتبقية من الأشهر السابقة.

## 🏗️ البنية المعمارية (Architecture)

يتبع المشروع نمط **Clean Architecture** المطور لضمان سهولة الصيانة والتوسع:

```
lib/
├── core/                  # الأدوات المساعدة، الثوابت، والوظائف المشتركة
├── data/                  # طبقة البيانات (Models & Local Storage)
│   ├── models/            # نماذج البيانات (Shopping, Wallet, Debt, etc.)
│   └── services/          # التخزين المحلي (LocalStorageService)
├── domain/                # طبقة الأعمال (Repositories Interfaces)
├── services/              # طبقة المنطق (Business Logic Services)
│   ├── backup_service.dart
│   ├── budget_service.dart
│   └── categories_service.dart
└── presentation/          # طبقة الواجهة (UI)
    ├── pages/             # الشاشات الأساسية (Home, Analytics, etc.)
    ├── widgets/           # المكونات القابلة لإعادة الاستخدام
    └── dialogs/           # النوافذ المنبثقة والرسائل
```

## 🔄 نظام النسخ الاحتياطي (Backup System)

يوفر **رادار المصروف** نظام نسخ احتياطي قوي:
1. **يدوي**: قم بتصدير ملف `json` يحتوي على كافة بياناتك ومشاركته أو حفظه.
2. **تلقائي**: يقوم التطبيق بعمل نسخة احتياطية دورية لضمان عدم ضياع البيانات.
3. **استعادة**: استرجع بياناتك من أي ملف نسخة احتياطية بضغطة زر.
